# Minesweeper

## **Create a modern web platform for playing Minesweeper**

We do not limit you in terms of functionality. Everything depends on your imagination, skills, and what you manage to complete within the time limit.

## Mandatory Requirements

**Your task:** create a product that stands out in the market, not just another copy of existing Minesweeper websites.

**Format:** web application

**Stack:** any language, any frameworks

**Tools:** you may use any AI tools and vibe coding platforms.
*For example: Lovable, Replit, Emergent, Bolt, v0, Cursor, ChatGPT, and others.*

## Level Requirements

### **1. "Weak" Level**

- **Functionality:** A static grid of cells. The user can click cells, but mine logic is not implemented: cells simply open; there are no flags, numbers, loss condition, or win condition.
- **Technical implementation:** Simple HTML/CSS and a bit of JS. No database.

**Result:**

This is just a "coursework project", not a product.

---

### **2. "Average" Level**

- **Functionality:** Basic game logic: mine generation, opening cells, displaying numbers next to mines, placing flags, detecting wins and losses. Several difficulty levels.
- **Technical implementation:** Clean code in React/Next.js. Game state is stored in local storage (LocalStorage).

**Result:**

A quality application, but there are thousands like it on the internet. No business potential.

---

### **3. "Strong" Level**

- **Functionality:** Timer, game history, win/loss statistics, best result for each difficulty level. Authentication and progress saving. Dark/light themes. Responsive interface for phones and tablets.
- **Technical implementation:** Supabase/Firebase for the database. Responsive design that is convenient to play on a phone.

**Result:**

A complete service. It is clear that the person is thinking about the user and user retention.

---

### **4. "Great" Level**

- **Functionality (features that were not requested):**
    - **Daily Challenge:** The same daily board for all users, with rankings by time and accuracy.
    - **AI Coach:** AI explains moves: "It is safer to open this cell here" or "This flag has a high probability of being correct".
    - **Social layer:** Global leaderboard by city, for example, "Top players from Almaty".
    - **Unique niche:** For example, "Minesweeper for training probabilistic thinking" or "fast 2-minute Minesweeper".
- **Business thinking:** The application already has an "Upgrade to Pro" button or Stripe integration for purchasing custom skins.
- **Result:** This is a ready startup prototype. The candidate showed that they can not only code, but also find ways to monetize and retain an audience.

---
