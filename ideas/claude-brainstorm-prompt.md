# Claude Brainstorm Prompt

I want you to brainstorm and create a complete product plan for my Minesweeper web app.

## Mission

Help me design a standout Minesweeper platform inspired by the way Chess.com turns chess into a full product: playing, learning, training, competition, rankings, progress, community, and retention.

The goal is not to make a simple Minesweeper clone. The goal is to create a product concept that feels like "Chess.com for Minesweeper": a place where users can play, improve, compete, analyze mistakes, train patterns, and come back every day.

## Output I Want

Create a new markdown file called `PROJECT_PLAN.md`.

Inside it, write a clear but not overly long project plan that I can use as the main roadmap for development.

The plan should include:

- Product vision and positioning
- Target users
- Core gameplay experience
- Main feature ideas
- MVP scope
- Strong "wow" features
- Pages/screens the app should have
- Learning/training system
- Competitive and leaderboard system
- Player stats and analytics
- AI coach ideas
- Social/community ideas
- Monetization or Pro ideas
- Suggested development phases
- What should go into the final README

## Context

The project is a modern web application for Minesweeper. The assignment rewards creativity, product thinking, retention, and business potential. A basic game is not enough.

Ideas I already like:

- Minesweeper Academy + Arena
- Daily Challenge with the same board for everyone
- Global, city, and university leaderboards
- AI Coach that explains safe moves, risky moves, and mistakes
- Probability overlay
- No-Guess / guaranteed-solvable mode
- Replay system
- Training missions for patterns like 1-2-1 and 1-2-2-1
- Player analytics such as win rate, solve time, flag accuracy, and mistake zones
- Multiplayer or ghost race mode
- Custom board creator and shareable challenges
- Free and Pro product layers

## Conditions

- Do not write code yet.
- Focus on product planning, feature design, user experience, and roadmap.
- Make the plan ambitious, but separate MVP features from later advanced features.
- Be realistic about what can be built first.
- Use Chess.com as inspiration, but adapt the ideas to Minesweeper instead of copying blindly.
- Think like a startup/product designer, not only like a developer.
- Keep the document structured, practical, and easy to read.
- Include enough detail that I can later ask an AI coding assistant to implement the project from the plan.

## Important Direction

I want the final product to feel like:

"A training and competitive platform for Minesweeper players, where beginners can learn logic and probability, intermediate players can improve, and advanced players can compete on daily challenges, rankings, and seasons."

Start by reading `description.md` and `extraIdeas.md` if they exist, then create `PROJECT_PLAN.md`.
